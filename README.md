# Chan Rim — Neuroimmunology Researcher

개인 연구 포트폴리오 웹사이트입니다. 기본 페이지는 한글이며, `en.html`에서 별도 영문 페이지를 제공합니다.

## 구성

- `index.html` — 한글 연구 포트폴리오
- `en.html` — 영문 연구 포트폴리오
- `styles.css` — Taste Skill 방향에 따른 반응형 레이아웃, 상태와 모션
- `DESIGN.md` — 디자인 방향, 토큰, 섹션 구성과 금지 규칙
- `app.js` — 논문 연도 필터, Research Lens, 모바일 메뉴와 영상 제어
- `manifest.webmanifest` — 모바일 홈 화면 설치용 메타데이터

논문 DOI와 한빛사 원문 링크는 원문 페이지로 연결됩니다. 논문 정보와 프로필 문구는 제공된 이력 내용을 바탕으로 구성했습니다.
